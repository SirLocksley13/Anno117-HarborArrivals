# Harbor Arrivals v1.0.0

## English

Harbor Arrivals is a live, read-only harbor dashboard for **Anno 117: Pax Romana**.

Select a harbor or trading post and press **Ctrl+Alt+H**. Confirmed arrivals appear on the native right-side panel with live ETA, ship name, route name, and current onboard cargo. The parchment focuses on current harbor operations: ships at harbor, loading/unloading, waiting/queue state, and other ships serving the harbor without a reliable current ETA.

### Highlights
- Live confirmed-arrival countdowns on the native right-side panel.
- Current onboard cargo shown read-only, with all detected goods retained and wrapped cleanly across lines.
- Harbor-now, loading/unloading and queue/waiting information on the parchment.
- Up to nine numbered parchment ships can be jumped to directly with **Ctrl+Alt+1–9**.
- **Ctrl+Alt+0** closes/returns from the parchment.
- Full runtime UI support for **English, German and French**.
- Bundled shared SirLocksley Parchment Controls Core for standalone installation.
- Read-only design: no changes to trade routes, cargo settings or ship assignments.

## Deutsch

Harbor Arrivals ist eine Live-Hafenübersicht mit rein lesendem Zugriff für **Anno 117: Pax Romana**.

Wähle einen Hafen oder Handelsposten aus und drücke **Ctrl+Alt+H**. Bestätigte Ankünfte erscheinen im nativen rechten Bereich mit Live-ETA, Schiffsname, Routenname und aktueller Ladung an Bord. Das Pergament konzentriert sich auf den aktuellen Hafenbetrieb: Schiffe im Hafen, Be-/Entladen, Warteschlangenstatus und weitere Schiffe ohne verlässliche aktuelle ETA.

### Höhepunkte
- Live-Ankunftszeiten im nativen rechten Bereich.
- Aktuelle Ladung an Bord wird read-only angezeigt; alle erkannten Waren bleiben sichtbar und werden sauber umgebrochen.
- Hafenstatus, Be-/Entladen und Warteschlangen auf dem Pergament.
- Bis zu neun nummerierte Pergament-Schiffe können mit **Ctrl+Alt+1–9** direkt angesprungen werden.
- **Ctrl+Alt+0** schließt das Pergament bzw. kehrt zurück.
- Vollständige Laufzeitoberfläche auf **Englisch, Deutsch und Französisch**.
- Gemeinsamer SirLocksley Parchment Controls Core ist für eine eigenständige Installation enthalten.
- Read-only: keine Änderung von Handelsrouten, Ladungseinstellungen oder Schiffszuweisungen.

## Français

Harbor Arrivals est un tableau de bord portuaire en direct et en lecture seule pour **Anno 117: Pax Romana**.

Sélectionnez un port ou un comptoir commercial puis appuyez sur **Ctrl+Alt+H**. Les arrivées confirmées apparaissent dans le panneau natif de droite avec ETA en direct, nom du navire, nom de la route et cargaison actuellement à bord. Le parchemin se concentre sur les opérations portuaires actuelles : navires au port, chargement/déchargement, attente/file d’attente et autres navires sans ETA actuelle fiable.

### Points forts
- Comptes à rebours d’arrivée en direct dans le panneau natif de droite.
- Cargaison actuelle affichée en lecture seule ; toutes les marchandises détectées restent visibles avec retour à la ligne propre.
- État du port, chargement/déchargement et file d’attente sur le parchemin.
- Jusqu’à neuf navires numérotés du parchemin sont accessibles directement avec **Ctrl+Alt+1–9**.
- **Ctrl+Alt+0** ferme/revient du parchemin.
- Interface dynamique complète en **anglais, allemand et français**.
- SirLocksley Parchment Controls Core partagé inclus pour une installation autonome.
- Lecture seule : aucune modification des routes commerciales, des réglages de cargaison ou des affectations de navires.
