# Changelog

## 1.0.0
- First public release of Harbor Arrivals.
- Native right-side confirmed-arrivals board with live ETA and onboard cargo.
- Structured parchment for harbor status, loading/unloading, queue/waiting and untimed serving ships.
- Parchment ship jump navigation through Ctrl+Alt+1–9 and Back through Ctrl+Alt+0.
- Full English, German and French runtime localization.
- Bundled SirLocksley Parchment Controls Core for standalone installation.
- Read-only gameplay design.
